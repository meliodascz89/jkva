# tools

Development tools that are not part of the engine build.

| Tool | Purpose |
|---|---|
| `wpt-runner` | runs a Web Platform Tests subset and reports pass rates (M1) |
| `reftest-diff` | screenshot and diff harness for the corpus (M1) |
| `bench-tracker` | stores benchmark runs and renders the public history (M4) |

Nothing here ships in a release.
